# לוח הבית: אפליקציית Expo

לוח הבית כאפליקציה לאייפון ולאנדרואיד (Expo SDK 58, React Native), בשלוש לשוניות:

- **לוח:** שעון ותאריך; מזג אוויר עם תחזית ל-5 ימים לעיר שבחרתם; מניות (עם מפתח Finnhub) ושערי הדולר
  והאירו; וחדשות בשלוש לשוניות: חדשות (ynet, mako, וואלה), מבזקים (ynet, מעריב) וספורט (ONE, ynet).
  משיכה למטה מרעננת. כשהרדיו מנגן, השם שלו מופיע בשעון ונגיעה בו עוצרת.
- **רדיו:** גלגלצ, גל"צ, כאן ב / גימל / 88, ‏103FM, רדיוס 100 וקול ברמה. הרדיו ממשיך לנגן כשעוברים
  לשונית. העוצמה בכפתורי הטלפון.
- **הגדרות:** חיפוש עיר או "המיקום שלי", מפתח Finnhub ורשימת מניות. נשמר במכשיר בלבד (AsyncStorage).

יש מצב בהיר וכהה לפי המכשיר.

## הרצה

צריך מחשב עם [Node.js](https://nodejs.org/) (גרסה 20 ומעלה).

```bash
cd expo-app
npm install
npx expo start
```

- **באייפון או באנדרואיד:** מתקינים את **Expo Go** מחנות האפליקציות, וסורקים את קוד ה-QR שמופיע
  בטרמינל (באייפון: עם המצלמה). הטלפון והמחשב צריכים להיות באותה רשת Wi-Fi.
- **בדפדפן:** לוחצים `w` בטרמינל.

כל שמירה של קובץ מתעדכנת מיד בטלפון.

## איפה מה

- `src/app/index.tsx`, `radio.tsx`, `settings.tsx`: שלושת המסכים. כל קובץ ב-`src/app/` הוא מסך (Expo Router).
- `src/lib/data.ts`: כל מקורות הנתונים ורשימת תחנות הרדיו.
- `src/state/settings.tsx` ו-`radio.tsx`: ההגדרות השמורות ונגן הרדיו, משותפים לכל המסכים.
- `src/components/app-tabs.tsx` ו-`app-tabs.web.tsx`: הלשוניות למטה (ולמעלה בדפדפן).
- `app.json`: שם האפליקציה, אייקונים והגדרות.

## מקורות הנתונים

- מזג אוויר וחיפוש ערים: [Open-Meteo](https://open-meteo.com/) (רישיון CC BY 4.0), בלי מפתח.
- חדשות, מבזקים וספורט: פידי ה-RSS של האתרים דרך rss2json, שמחזיר עד 10 כותרות לאתר.
- מניות: [Finnhub](https://finnhub.io/), עם מפתח חינמי אישי. שערי מטבע: [Frankfurter](https://frankfurter.dev/), יומיים.
- רדיו: שידורי האינטרנט הרשמיים של התחנות.

## הערות

- **רדיו ברקע:** ב-Expo Go הרדיו עלול להיעצר כשיוצאים מהאפליקציה או נועלים את המסך. ניגון ברקע ופקדים
  במסך הנעילה דורשים גרסת פיתוח (`npx expo run:ios` עם Xcode, או `eas build --profile development`).
  ההגדרה כבר נמצאת ב-`app.json` (תוסף `expo-audio`).
- **התקנת חבילות:** משתמשים ב-`npx expo install <חבילה>` כדי לקבל גרסה שמתאימה ל-SDK.

- בגרסת הדפדפן הדף נבנה קודם בשרת, ולכן הלוח מצויר רק אחרי שהוא נטען במכשיר (ראו `useMounted`
  ב-`index.tsx`), ונגן הרדיו נוצר רק במכשיר (ב-`src/state/radio.tsx`). בשרת אין שעון מקומי, מצב צבעים
  או תמיכה בשמע.
- בקובץ התבנית `src/components/app-tabs.web.tsx` יש שגיאת טיפוסים שמגיעה מהתבנית של Expo עצמה. היא לא
  משפיעה על ההרצה.
- התיקייה הזו לא חלק מבניית האתר: האתר נבנה רק מ-`src/` שבשורש המאגר.
