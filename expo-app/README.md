# לוח הבית: אפליקציית Expo

גרסה ראשונה של לוח הבית כאפליקציה לאייפון ולאנדרואיד (Expo SDK 58, React Native): שעון ותאריך,
מזג אוויר לתל אביב עם תחזית ל-5 ימים, וכותרות מ-ynet ו-mako. משיכה למטה מרעננת, ויש מצב בהיר וכהה
לפי המכשיר.

## הרצה

צריך מחשב עם [Node.js](https://nodejs.org/) (גרסה 20 ומעלה).

```bash
cd expo-app
npm install
npx expo start
```

- **באייפון או באנדרואיד:** מתקינים את **Expo Go** מחנות האפליקציות, וסורקים את קוד ה-QR שמופיע
  בטרמינל (באייפון: עם המצלמה). הטלפון והמחשב צריכים להיות באותה רשת Wi-Fi.
- **בדפדפן:** לוחצים `w` בטרמינל.

כל שמירה של קובץ מתעדכנת מיד בטלפון.

## איפה מה

- `src/app/index.tsx`: המסך הראשי (הלוח). כל קובץ ב-`src/app/` הוא מסך (Expo Router).
- `src/components/app-tabs.tsx` ו-`app-tabs.web.tsx`: הלשוניות למטה (ולמעלה בדפדפן).
- `app.json`: שם האפליקציה, אייקונים והגדרות.

## מקורות הנתונים

- מזג אוויר: [Open-Meteo](https://open-meteo.com/) (רישיון CC BY 4.0), בלי מפתח.
- חדשות: פידי ה-RSS של ynet ו-mako דרך rss2json, שמחזיר עד 10 כותרות לאתר.

## הערות

- בגרסת הדפדפן הדף נבנה קודם בשרת, ולכן המסך מצויר רק אחרי שהוא נטען במכשיר (ראו `useMounted`
  ב-`index.tsx`); אחרת השעה ומצב הצבעים בשרת לא תואמים לאלה של המכשיר.
- בקובץ התבנית `src/components/app-tabs.web.tsx` יש שגיאת טיפוסים שמגיעה מהתבנית של Expo עצמה. היא לא
  משפיעה על ההרצה.
- התיקייה הזו לא חלק מבניית האתר: האתר נבנה רק מ-`src/` שבשורש המאגר.
