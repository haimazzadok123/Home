# המדריך לפילדלפיה

אתר סטטי (HTML/CSS/JS ללא build step) שמציג את האטרקציות השוות בפילדלפיה — עם קטגוריה, מחיר
כניסה משוער, משך ביקור, וזמן הגעה משוער (הליכה / SEPTA) מ-City Hall (מרכז העיר). לכל אתר יש
כפתור ניווט שפותח מסלול חי ב-Google Maps מהמיקום הנוכחי של המשתמש, וגם מפה אינטראקטיבית
(Leaflet + OpenStreetMap) עם כל הנקודות.

## הרצה מקומית

אין תלות ב-npm — פשוט מריצים שרת סטטי מהתיקייה הזו, למשל:

```bash
python3 -m http.server 8765
```

ואז פותחים `http://localhost:8765`.

## מבנה

- `index.html` — מבנה הדף
- `style.css` — עיצוב (תומך מצב כהה/בהיר אוטומטית)
- `data.js` — רשימת האטרקציות (שם, קטגוריה, מיקום, מחיר, זמני הגעה, טיפים)
- `app.js` — סינון, חיפוש, מיון והצגת המפה
- `vendor/leaflet` — עותק מקומי של ספריית Leaflet (כדי לא להיות תלויים ב-CDN חיצוני)

## הערה

מחירי הכניסה וזמני ההגעה הם הערכה, נכונים למועד הכתיבה — מומלץ לבדוק באתר הרשמי של כל אתר
לפני הביקור בפועל.
