# מטיילים עם דוד חיים

אפליקציית תכנון מסלולי טיול: בוחרים נקודת יציאה ונקודת יעד, מקבלים מסלול נסיעה על גבי מפה,
ולאורך המסלול מוצגות נקודות תצפייה נופיות, מקומות אוכל כשר, ועגלות קפה (מסננים כל קטגוריה
בנפרד, וניתן לשלוט על רוחב "המסדרון" של החיפוש סביב המסלול).

## טכנולוגיה

פרויקט React + TypeScript + Vite, ללא שרת משלו — כל הנתונים מגיעים משירותי OpenStreetMap
חינמיים וללא צורך במפתח API:

- **חיפוש מקומות (geocoding):** [Nominatim](https://nominatim.org/)
- **תכנון מסלול נסיעה:** [OSRM](https://project-osrm.org/) (שרת הדגמה ציבורי)
- **נקודות עניין (תצפיות / אוכל כשר):** [Overpass API](https://overpass-api.de/) על נתוני OpenStreetMap
- **עגלות קפה:** רשימה קבועה בקוד (`src/data/coffeeCarts.ts`), מבוססת [Coffee Trail](https://coffeetrail.co.il/) —
  לא נמשכת דינמית מ-OpenStreetMap
- **מפה:** [Leaflet](https://leafletjs.com/) עם אריחי OpenStreetMap
- **חישובי מרחק מהמסלול:** [Turf.js](https://turfjs.org/)

## הרצה מקומית

```bash
npm install
npm run dev
```

פקודות נוספות: `npm run build` לבנייה לפרודקשן, `npm run lint` להרצת בודק הסגנון.

## איך זה עובד

1. מחפשים נקודת יציאה ונקודת יעד (חיפוש חופשי, מבוסס Nominatim).
2. לוחצים "תכנון מסלול" — מתקבל מסלול נסיעה מ-OSRM ומצויר על המפה.
3. האפליקציה בונה תיבת חיפוש (bounding box) סביב המסלול ברוחב שנבחר (1–20 ק"מ), ושואלת את
   Overpass על נקודות תצפייה (`tourism=viewpoint`) ומקומות עם תיוג כשרות
   (`diet:kosher=yes`, `cuisine=kosher`, `shop=kosher`), ומצרפת אליהן את רשימת עגלות הקפה
   הקבועה מ-`coffeeCarts.ts`.
4. לכל נקודת עניין מחושב המרחק מהמסלול ומיקומה לאורכו, כדי למיין ולסנן אותה.

## מגבלות ידועות

- תיוג כשרות ב-OpenStreetMap חלקי — לא כל מקום כשר בהכרח מתויג ככזה, אז חלק מהמקומות עלולים
  לא להופיע.
- סינון המשנה לאוכל כשר (בשרי/חלבי) מבוסס על ניחוש מתגיות לא סטנדרטיות ומילות מפתח בשם/סוג
  המטבח, ולכן עוד פחות אמין מתיוג הכשרות עצמו — חלק מהמקומות לא יסווגו נכון. סינון סוג המקום
  (מסעדה/מזון מהיר) מבוסס על תגית `amenity` הסטנדרטית ולכן אמין יותר.
- שרתי ה-API הציבוריים (Nominatim / OSRM / Overpass) מוגבלים בקצב הבקשות ומיועדים לשימוש
  קליל; לשימוש כבד/מסחרי כדאי לעבור לשירותים בתשלום או לארח מופע עצמאי.
- תכנון המסלול הוא לנסיעה ברכב בלבד (`driving` profile ב-OSRM).
